# 文件加密打包器（File Locker）

把任意文件打包成一个独立的 `.exe` 分享给他人。接收者双击打开后，点击「解锁文件」按钮，按你设置的解锁方式获得文件：

- **打开网页链接**：点击后自动用默认浏览器打开你指定的链接，然后获得文件（适合引流/推广）
- **回答问题**：弹出你设置的题目，接收者必须答对才能获得文件（适合简单口令保护）

生成的 EXE 无需安装 Python，可直接在 Windows 上运行。

## 环境要求

- Python 3.8+
- Windows（生成 `.exe`；接收者运行 EXE 无任何环境要求）

## 安装

```bash
pip install -r requirements.txt
```

> 未安装 PyInstaller 时，程序在首次生成 EXE 时会自动检测并提示安装。

## 使用方法

```bash
python file_locker.py
```

1. 点击「浏览...」选择需要保护的文件
2. 选择解锁方式，并填写对应内容：
   - 打开网页链接：填写解锁时要打开的 URL（不带 `http(s)://` 时会自动补全）
   - 回答问题：填写问题和正确答案（答案区分大小写，忽略首尾空格）
3. 点击「生成 EXE」，选择保存位置
4. 把生成的 EXE 分享给别人即可

## 工作原理

- 原文件使用 **LZMA** 压缩后，连同解锁配置（链接 / 问题 / 答案的 SHA-256）一起作为数据包嵌入 EXE（PyInstaller `--onefile` + `--add-data`）
- 接收者解锁成功后，先解压并通过 **SHA-256 校验** 文件完整性，再选择保存位置释放文件
- 题目答案在 EXE 中只保存哈希值，界面上看不到明文

## 注意事项

- 生成的 EXE 约 10 MB（PyInstaller 单文件模式的固有开销），实际文件越大 EXE 越大
- 杀毒软件可能对 PyInstaller 打包的程序误报，属正常现象，添加信任即可
- 本项目是轻量级的文件分发保护工具，**并非强加密方案**，请勿用于保护高价值机密文件
- 单个文件请勿超过 1 GB
